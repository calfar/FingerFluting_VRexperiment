# FingerFluting_VRexperiment

Make sure to open in Unity Version 2022.3.11f1 or later.

You'll need to purchase the Drawing Board VR addon in the unity asset store, link here: https://assetstore.unity.com/packages/tools/painting/drawing-board-vr-253359#description

Alternatively you can implement your own drawing system, but this one works really well out of the box.
